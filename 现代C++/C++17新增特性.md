# C++17 新增特性

> C++17 是 C++11 之后一次**实质性的标准化**：引入结构化绑定、`if constexpr`、折叠表达式、`optional/variant/any`、`string_view`、文件系统等大批实用能力，代码风格显著现代化。本文件按版本增量逐条罗列，并为每个特性标注其在 C++11 基础模块中的出处。

## 1. 结构化绑定（structured bindings）

**所属 C++11 模块**：`C++常用标准库详解.md`（`std::tuple`/`std::tie`）、`STL六大组件全详解.md`（`std::pair`）。

将元组/pair/聚合对象的成员一次性解包为多个变量：

```cpp
// 元组
auto [x, y] = std::make_pair(1, 2.5);        // x:int, y:double

// map 遍历解包
for (const auto& [k, v] : my_map) { ... }

// 结构化绑定数组
int a[3] = {1,2,3};
auto& [p, q, r] = a;                          // 引用绑定

// 返回 struct
struct Result { int code; std::string msg; };
Result r = f();
auto [c, m] = r;
```

- 按引用（`auto&`）可修改；`const auto&` 只读。
- 相比 `std::tie`：无需预先声明变量、无需 `std::ignore`，更简洁。

**价值**：让多返回值/键值对遍历的代码大幅简化，是现代 C++ 最常用的写法之一。

## 2. `if` / `switch` 初始化语句

**所属 C++11 模块**：`C++核心语法详解.md`（流程控制）。

在 `if`/`switch` 条件前声明并初始化一个**局部变量**，其作用域限缩到该语句块：

```cpp
if (auto it = m.find("k"); it != m.end()) {
    use(it->second);      // it 仅在此 if 块可见
}

switch (int v = read(); v) {
    case 1: ...;
}
```

**价值**：把“获取结果 + 条件判断”合并，避免变量泄漏到外层作用域（缩小作用域，提升可读性与安全性）。

## 3. `inline` 变量

**所属 C++11 模块**：`C++内存模型与对象模型.md`（ODR/头文件组织）、`类和对象.md`（静态成员）。

C++11 中头文件里的全局/静态变量定义会触发 ODR 冲突。C++17 允许 `inline` 变量在头文件定义且**程序内仅一份**：

```cpp
// 头文件
struct Config {
    static inline std::string name = "svc";   // 类内定义，无需类外定义
};
inline int global_counter = 0;                // 头文件安全定义
```

**价值**：免去“头文件声明 + cpp 定义”的样板；类内静态常量/变量可直接就地定义。

## 4. `if constexpr`

**所属 C++11 模块**：`模板与泛型编程思想.md`（SFINAE/类型分发）。

**编译期**分支：根据模板实参在编译期选择代码分支，未选中的分支**不实例化**：

```cpp
template <typename T>
void print(const T& v) {
    if constexpr (std::is_integral<T>::value) {
        std::cout << "int: " << v << '\n';
    } else if constexpr (std::is_same<T, std::string>::value) {
        std::cout << "str: " << v << '\n';
    } else {
        static_assert(std::is_floating_point<T>::value, "unsupported type");
    }
}
```

- 条件必须为编译期常量表达式。
- 替代大量 SFINAE/`enable_if` 重载，代码直白。

**价值**：是模板代码“按类型分支”的最清晰手段，显著减少元编程复杂度。

## 5. 折叠表达式（fold expressions）

**所属 C++11 模块**：`模板与泛型编程思想.md`（变参模板）。

对参数包应用二元运算符，省略手写递归展开：

```cpp
template <typename... Args>
auto sum(Args... args) { return (args + ...); }        // 一元右折叠
// sum(1,2,3) == ((1+2)+3)

template <typename... Args>
bool all_true(Args... args) { return (args && ...); } // 折叠到 &&

template <typename... Args>
void print(Args... args) {
    (std::cout << ... << args);                        // 折叠输出
}
```

- 运算符必须在包两边形成合法折叠（`(args op ...)` 右折叠 / `(... op args)` 左折叠）。
- 初值折叠 `(init op ... op args)`。

**价值**：变参模板的展开从递归简化为单表达式，简洁且类型安全。

## 6. 属性扩展

**所属 C++11 模块**：`类和对象.md`（声明）、`C++核心语法详解.md`。

- **`[[maybe_unused]]`**：抑制“未使用”告警。
- **`[[nodiscard]]`**：返回值不可忽略，忽略则告警。
- **`[[fallthrough]]`**：显式声明 `switch` 贯穿是故意为之。

```cpp
[[nodiscard]] int compute() { return 42; }
compute();                        // 告警：返回值被忽略

void h(int v) {
    switch (v) {
        case 1: do_a();
            [[fallthrough]];      // 明确贯穿到 case 2
        case 2: do_b(); break;
    }
}
```

**价值**：把“意图”写入代码，编译器帮助发现错误（漏用返回值、误贯穿）。

## 7. `std::optional` / `std::variant` / `std::any`

**所属 C++11 模块**：`C++常用标准库详解.md`（`<memory>`/`<utility>`）、`模板与泛型编程思想.md`。

### 7.1 `std::optional<T>`（`<optional>`）

表示“可能有值，也可能为空”——替代“返回 -1 表示失败”的约定：

```cpp
std::optional<int> parse(const std::string& s) {
    try { return std::stoi(s); } catch (...) { return std::nullopt; }
}
auto v = parse("42");
if (v) { use(*v); }              // 判存在 + 解引用
v.value_or(0);                    // 空时给默认值
```

### 7.2 `std::variant<A,B,...>`（`<variant>`）

类型安全的**联合体**：同一时刻保存其中一种类型：

```cpp
std::variant<int, std::string, double> v;
v = 42;                                  // 当前为 int
v = "hello";                             // 切换为 string
std::visit([](auto&& x){ print(x); }, v); // 按当前类型分派
```

- 无空状态；访问错误类型抛 `std::bad_variant_access`（`get`）或返回 `nullptr`（`get_if`）。

### 7.3 `std::any`（`<any>`）

可保存**任意可拷贝类型**（类型擦除的容器）：

```cpp
std::any a = 3.14;
if (a.type() == typeid(double)) {
    double d = std::any_cast<double>(a);
}
```

- 无类型信息、需显式 `any_cast`；滥用会损失类型安全，适合极少数动态场景。

**价值**：把“可选值 / 多态值 / 动态值”的表达标准化，替代大量手写哨兵值与 `void*`。

## 8. `std::string_view`（`<string_view>`）

**所属 C++11 模块**：`C++常用标准库详解.md`（`<string>`）。

对字符串的**只读非拥有视图**：保存指针 + 长度，不拷贝：

```cpp
void consume(std::string_view sv) { /* 只读使用 */ }
consume("literal");                  // 无需转 std::string
std::string s = "abc";
consume(s);                          // 零拷贝传入
```

- **不拥有数据**：不能指向临时对象超出其生命周期。
- 用于**函数参数**（替代 `const std::string&` 只读入参）与**子串视图**。

**价值**：避免字符串参数的无谓拷贝与临时构造，提升性能；是高性能 C++ 的常见约定。

## 9. `std::filesystem`（`<filesystem>`）

**所属 C++11 模块**：`C++常用标准库详解.md`（`<fstream>`）。

跨平台文件系统操作（C++17 正式标准化）：

```cpp
namespace fs = std::filesystem;
fs::path p = "data/log.txt";
if (fs::exists(p)) {
    auto sz = fs::file_size(p);
    for (const auto& e : fs::directory_iterator("data")) { ... }
}
fs::create_directories("a/b/c");
fs::remove(p);
```

核心：`path`、`exists`、`is_directory`、`file_size`、`directory_iterator`、`create_directories`、`remove`、`rename`、`copy`。

**价值**：替代平台各自文件 API 的胶水代码，实现可移植的文件系统操作。

## 10. 并行算法（execution policy）

**所属 C++11 模块**：`STL六大组件全详解.md`（算法）、`C++并发编程.md`。

为算法增加执行策略参数，让算法**自动并行/向量化**：

```cpp
#include <execution>
std::vector<int> v(1000000);
std::sort(std::execution::par, v.begin(), v.end());       // 并行
std::transform(std::execution::par_unseq, v.begin(), v.end(),
               v.begin(), [](int x){ return x*x; });
```

策略：`seq`（串行）、`par`（并行）、`par_unseq`（并行+向量化）。

**价值**：一行代码把串行算法升级为并行，前提是**谓词须无数据竞争、无副作用依赖**。

## 11. 新的 `new`/`delete` 对齐重载与 `over_aligned`

**所属 C++11 模块**：`C++内存模型与对象模型.md`（对齐/内存管理）。

C++17 为超对齐类型提供专用的分配函数（`operator new(size, align_val_t)`），使 `new` 自动满足对齐要求：

```cpp
struct alignas(64) CacheLine { int data; };
auto p = new CacheLine;      // 分配器自动对齐 64
```

**价值**：超对齐对象（SIMD、缓存行）的堆分配不再依赖平台特化 API。

## 12. 其他语言与库改进

|---|---|
| `std::apply` / `std::make_from_tuple` | 元组展开为函数参数 |
| `std::clamp` | 值限幅 |
| `std::gcd` / `std::lcm`（`<numeric>`） | 最大公约数/最小公倍数 |

| `std::byte`（`<cstddef>`） | 字节类型，替代 `char` 做字节运算 |

| 类模板实参推导（CTAD） | `std::vector v{1,2,3};` 自动推导类型 |

```cpp
std::vector v{1, 2, 3};          // CTAD：推导为 vector<int>
int c = std::clamp(x, 0, 100);   // 限幅
```
