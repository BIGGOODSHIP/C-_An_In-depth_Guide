## 1. 概念与约束（concepts）

**所属 C++11 模块**：`模板与泛型编程思想.md`（类型约束/SFINAE）。

**概念**是一组对模板类型参数的要求，把“模板对类型的最小要求”显式化，替代晦涩的 SFINAE：

```cpp
#include <concepts>

template <typename T>
concept Integral = std::is_integral_v<T>;         // 定义概念

template <Integral T>                              // 用法：约束 T
T half(T v) { return v / 2; }

// requires 子句约束
template <typename T>
requires std::copyable<T>
void copy_to(T& dst, const T& src) { dst = src; }

// 概念可与 auto 结合
template <std::random_access_iterator It> ...      // 迭代器概念
```

- 内置概念：`std::integral`、`std::floating_point`、`std::same_as`、`std::copyable`、`std::random_access_iterator` 等。
- 优点：**更清晰的错误信息**（约束失败直接说明不满足哪个概念）、**更好的重载决议**、可读性强的约束表达。

**价值**：把泛型约束从“编译错误迷宫”升级为“自文档化的接口契约”。

## 2. 三路比较运算符 `<=>`（spaceship）

**所属 C++11 模块**：`类和对象.md`（运算符重载）。

`<=>` 一次比较返回 **`std::strong_ordering` / `std::weak_ordering` / `std::partial_ordering`**，编译器可据此自动生成 `<`、`>`、`==` 等：

```cpp
#include <compare>

struct Point {
    int x, y;
    auto operator<=>(const Point&) const = default;   // 自动生成所有比较
    bool operator==(const Point&) const = default;
};
Point a{1,2}, b{1,3};
a < b;    // 逐成员比较
```

- `= default` 按声明顺序逐成员比较。
- 通过 `std::strong_ordering` 等表达比较语义（是否等价、是否可无序）。

**价值**：一行代码搞定完整排序/比较关系，消除手写 6 个运算符的样板。

## 3. 范围（ranges）与管道

**所属 C++11 模块**：`STL六大组件全详解.md`（迭代器/算法）、`函数式编程思想.md`。

Ranges 让算法直接作用于**容器/视图**（而非迭代器对），并通过 `|` 管道组合：

```cpp
#include <ranges>

std::vector<int> v{3,1,4,1,5,9,2,6};
auto result = v
    | std::views::filter([](int x){ return x % 2 == 0; })
    | std::views::transform([](int x){ return x * x; });

for (int x : result) { ... }        // 惰性、零拷贝
```

- **视图（view）**：不拥有数据、惰性求值、可组合（filter/transform/take/drop/reverse 等）。
- **范围算法**：`std::ranges::sort(v)`、`std::ranges::find_if(v, pred)` 直接接受容器。
- **哨兵（sentinel）** 允许非相同类型的 begin/end。

**价值**：用声明式管道表达数据转换链，替代手写循环，代码更接近业务意图。

## 4. 协程（coroutines）

**所属 C++11 模块**：`C++并发编程.md`（异步/任务）。

协程是**可挂起/恢复**的函数：`co_await` 挂起等待异步结果，`co_yield` 产出值，`co_return` 返回。框架（如生成器、task）通过承诺类型定制行为：

```cpp
#include <generator>   // C++23 才有标准生成器；C++20 需自定义/第三方

// 生成器示例（示意，C++20 生态）
Generator<int> gen() {
    for (int i = 0; i < 5; ++i) co_yield i;   // 每次产出后挂起
}
```

- 关键字：`co_await`、`co_yield`、`co_return`。
- 核心价值：**以同步代码的写法编写异步逻辑**，避免回调地狱，栈式局部变量保留。
- 适用于：异步 I/O、事件循环、惰性生成、状态机。
- C++20 标准只提供语言机制与约定，`std::generator` 在 C++23 才进入标准库。

**价值**：让异步编程从“回调嵌套”走向“顺序化表达”，是现代高性能服务的核心范式。

## 5. 模块（modules）

**所属 C++11 模块**：`C++核心语法详解.md`（头文件/预处理）、`C++内存模型与对象模型.md`（ODR）。

模块取代头文件/宏包含体系，提供**真正的组件边界与编译隔离**：

```cpp
// math.cppm
export module math;
export int add(int a, int b) { return a + b; }

// main.cpp
import math;                     // 导入模块
int r = add(1, 2);
```

- 优点：**编译时间显著下降**（模块一次性解析）、**消除宏污染**、明确导出边界。
- 生态仍在迁移中（工具链支持度逐步成熟）。

**价值**：从“文本包含”走向“组件化”，是 C++ 编译模型的重要演进方向。

## 6. 指定初始化（designated initializers）

**所属 C++11 模块**：`C++核心语法详解.md`（聚合初始化）。

允许按**成员名**初始化聚合对象，提高可读性与健壮性：

```cpp
struct Config { int port; std::string host; bool verbose; };
Config c = {.port = 8080, .host = "localhost", .verbose = true};
```

- 必须按声明顺序、不能跳过（可用 C++20 的替代机制处理）。
- 赋值错误由成员名约束，减少“位置记错”类错误。

**价值**：聚合配置类初始化更自描述、更不易出错。

## 7. 新增关键字与语法改进

| 语法 | 说明 |
|---|---|
| `consteval` | **必须**在编译期求值的函数（与 `constexpr` 的“尽量”相对） |
| `constinit` | 强制静态存储期对象常量初始化 |
| `char8_t` | 明确 UTF-8 字符类型（`u8'...'`） |
| 位域默认初始化 | `int a : 3 = 0;` |
| Lambda 模板形参 | `[]<typename T>(T v){}` |
| `std::endian` | 检测字节序 |
| 数组 `operator[]` | 支持多维下标参数 |

```cpp
consteval int sq(int x) { return x * x; }   // 编译期强制
constexpr int r = sq(4);
```

## 8. 标准库新增：`<span>` / `<chrono>` 日历 / `jthread`

### 8.1 `std::span`（`<span>`）

对**连续元素**的非拥有视图（类似 string_view 对数组）：

```cpp
#include <span>
void process(std::span<int> data) {      // 接受 vector/array/裸数组
    for (int& x : data) { x *= 2; }
}
std::vector<int> v{1,2,3};
process(v);
```

**价值**：作为“连续区间”的通用只读/可修改接口，替代裸指针+长度。

### 8.2 `<chrono>` 日历与时区

C++20 为 chrono 增加日期/时钟/时区类型：

```cpp
using namespace std::chrono;
auto d = 2026_y / 9 / 30;              // 日期字面量
auto tp = sys_days{d} + 10h;           // 时间点运算
// 时区转换、weekday、格式化输出（format）
```

### 8.3 `std::jthread`（`<thread>`）

**join 线程**：析构自动 `join()`，且支持**可取消**（`request_stop`/`stop_token`）：

```cpp
std::jthread t([](std::stop_token st){
    while (!st.stop_requested()) { work(); }
});
t.request_stop();    // 请求停止；析构自动 join
```

**价值**：解决裸 `std::thread` 忘 join 导致 `terminate` 的问题，并原生支持协作式取消。

## 9. `std::format`（`<format>`）

**所属 C++11 模块**：`C++常用标准库详解.md`（`<sstream>` 格式化）。

类 Python 的类型安全格式化：

```cpp
#include <format>
std::string s = std::format("{} + {} = {}", 1, 2, 3);   // "1 + 2 = 3"
std::string p = std::format("{:.2f}", 3.14159);          // "3.14"
std::format("{:#x}", 255);                               // "0xff"
```

- 编译期校验格式串（C++20 起）、类型安全、性能优于 `ostringstream`。

**价值**：取代 `ostringstream`/`snprintf`，成为现代 C++ 标准格式化方式。

## 10. `std::source_location`（`<source_location>`）

**所属 C++11 模块**：`C++核心语法详解.md`（预处理/宏）。

标准化的调用位置信息（替代 `__FILE__`/`__LINE__` 宏）：

```cpp
#include <source_location>
void log(const std::string& msg,
         const std::source_location loc = std::source_location::current()) {
    std::cerr << loc.file_name() << ":" << loc.line() << " " << msg << '\n';
}
```

**价值**：日志/诊断可精确记录调用点，替代宏并支持默认参数。

```cpp
std::vector<int> v{1,2,2,3};
std::erase(v, 2);                          // 就地删除所有 2
int cnt = std::popcount(0b1011u);          // 3
```
