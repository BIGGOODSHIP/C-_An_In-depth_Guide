## 1. 语言特性：`deducing this`（显式对象参数）

**所属 C++11 模块**：`类和对象.md`（成员函数/多态）。

允许在成员函数参数列表中**显式书写对象参数 `this`**（`Self&&`），使成员函数模板化，并区分左值/右值调用，替代传统的 `const`/非 `const` 双写：

```cpp
struct Widget {
    void mutate(this Widget& self);      // 显式对象参数
    // 或模板化：支持 const 与 mutable 复用
    template <typename Self>
    void f(this Self&& self);
};
```

- 解决“同一逻辑因 const/mutable/volatile 写多份”的问题。
- 为 CRTP 等提供更简洁的写法。
- 递归 Lambda（定义时就可用自身）也得益于此。

**价值**：简化成员函数模板与 const/非 const 重载，减少样板。

## 2. Lambda 与语法改进

**所属 C++11 模块**：`函数式编程思想.md`。

- **递归 Lambda 简化**（配合 deducing this）：
```cpp
auto fib = [](this auto self, int n) -> int {
    return n < 2 ? n : self(n-1) + self(n-2);
};
```
- **`static`/`static operator()`**：无捕获静态调用操作符，可转换函数指针。
- **多维下标 `operator[]`**：`a[i, j]` 支持多参数。
- 放宽 `constexpr` 的更多限制（可变 Lambda、`union` 等）。

## 3. `std::expected`（`<expected>`）

**所属 C++11 模块**：`C++常用标准库详解.md`（`<memory>`/`<utility>`）、`C++17新增特性.md`（`std::optional`）。

承载**“成功值 或 错误值”**的显式错误处理类型，优于异常或哨兵值：

```cpp
#include <expected>
using Result = std::expected<int, std::string>;

Result parse(const std::string& s) {
    if (s.empty()) return std::unexpected("empty input");
    return std::stoi(s);
}

auto r = parse("42");
if (r) { use(*r); }                 // 成功值
else { handle(r.error()); }        // 错误值
r.value_or(-1);
```

- 与 `optional` 不同：**空态也携带错误信息**。
- 支持 `and_then`/`transform` 链式组合。

**价值**：把“值 + 错误”显式建模，适用于性能敏感、不宜抛异常或需错误可读的路径。

## 4. `std::mdspan`（`<mdspan>`）

**所属 C++11 模块**：`C++核心语法详解.md`（多维数组）、`C++20新增特性.md`（`std::span`）。

对**任意连续存储**提供多维非拥有视图，支持布局策略与下标映射：

```cpp
#include <mdspan>
double data[16];
std::mdspan<double, std::extents<4,4>> m(data);   // 4x4 视图
m[1, 2] = 3.5;                                     // 行主序访问
```

- 类型化维度 `extents`、布局策略（行主序/列主序）、下标访问。
- 是科学计算/线性代数库的基石。

**价值**：把裸指针+维度计算封装为类型安全的多维区间，为高性能数值计算提供标准抽象。

## 5. 扁平容器：`std::flat_map` / `std::flat_set`

**所属 C++11 模块**：`STL六大组件全详解.md`（`map`/`set` 底层与对比）。

用**排序的连续存储**（默认 `vector`）实现关联容器语义：

```cpp
#include <flat_map>
std::flat_map<int, std::string> fm{{1,"a"},{2,"b"}};
fm[3] = "c";
```

- 底层为两个 vector（键、值），按序存储。
- **优点**：缓存友好、内存紧凑、遍历快，构建期开销小。
- **缺点**：插入/删除 O(n)（搬移）；迭代器在修改后可能失效。

**价值**：当“构建后查询为主、修改少”且重缓存局部性时，替代红黑树 `map`，显著提升性能。

## 6. 范围（ranges）增强

**所属 C++11 模块**：`STL六大组件全详解.md`（算法/迭代器）、`C++20新增特性.md`（ranges）。

- **`std::ranges::to`**：把视图/范围物化为容器。
- **`views::zip` / `views::enumerate` / `views::adjacent` / `views::chunk`**：元素组合、计数、相邻、分块。
- **`views::cartesian_product`**：笛卡尔积。
- 改进的 `std::ranges::fold_left`、`join_with` 等。

```cpp
std::vector<int> a{1,2,3}, b{10,20,30};
for (auto [x, y] : std::views::zip(a, b)) { /* (1,10),(2,20),(3,30) */ }
```

**价值**：ranges 生态补齐，数据变换链表达力进一步扩展。

## 7. `std::generator`（`<generator>`）

**所属 C++11 模块**：`C++并发编程.md`（协程）、`C++20新增特性.md`（协程）。

**标准协程生成器**：以 `co_yield` 惰性产出序列：

```cpp
#include <generator>
std::generator<int> evens(int n) {
    for (int i = 0; i < n; ++i)
        if (i % 2 == 0) co_yield i;
}
for (int v : evens(10)) { use(v); }    // 惰性、按需生产
```

- 通过范围适配器直接消费；协程生态标准化的关键一步。

**价值**：让“惰性序列/数据流”用标准库表达，无需自定义协程框架。

## 8. 栈回溯 `std::stacktrace`（`<stacktrace>`）

**所属 C++11 模块**：`C++核心语法详解.md`（异常处理）。

**标准栈回溯**，为诊断提供调用链：

```cpp
#include <stacktrace>
auto st = std::stacktrace::current();          // 当前调用栈
for (const auto& e : st)
    std::cerr << e.description() << " at " << e.source_file()
              << ":" << e.source_line() << '\n';
```

- `current()` 捕获当前栈；`description()`/`source_file()`/`source_line()` 输出帧信息。

**价值**：替代平台专用回溯工具，用于日志与错误诊断。

## 9. 字符串与格式化增强

**所属 C++11 模块**：`C++常用标准库详解.md`（`<string>`/`<sstream>`）。

- **`std::format` 增强**：支持 `std::print`（直接打印到流）、`format_to`、更多格式（区间、指针、错误码）。
- **`std::string::contains`**：子串存在判断。
- **`std::string::starts_with` / `ends_with`**：前缀/后缀判断。

```cpp
std::string s = "hello world";
s.starts_with("hel");      // true
s.contains("wor");         // true
```

**价值**：字符串常见判断加入标准，简化高频写法。
