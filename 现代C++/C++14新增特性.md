# C++14 新增特性

> C++14 是对 C++11 的**增量修正与增强**，主要放宽了 C++11 的若干保守限制，使代码更简洁。C++14 被广泛视为“C++11 的完善版”。本文件逐条罗列 C++14 新增/改进特性，并为每个特性标注其在 C++11 基础模块中的出处，便于联动查阅。

## 1. 泛型 Lambda（generic lambda）

**所属 C++11 模块**：`函数式编程思想.md`（Lambda 表达式）。

C++11 的 Lambda 形参必须为具体类型。C++14 允许形参使用 `auto`，使 Lambda 成为**模板化**的可调用对象：

```cpp
// C++11
auto twice_int = [](int x) { return x * 2; };

// C++14：泛型 Lambda
auto twice = [](auto x) { return x * 2; };
twice(3);         // int
twice(2.5);       // double
```

- 每个 `auto` 形参对应一个模板类型参数（编译器生成仿函数的 `operator()` 模板）。
- 可与完美转发结合：

```cpp
auto wrap = [](auto&& v) { return inner(std::forward<decltype(v)>(v)); };
```

**价值**：把 Lambda 升级为模板，同一闭包复用多类型，减少重复定义。

## 2. 返回值类型推导（return type deduction）

**所属 C++11 模块**：`C++核心语法详解.md`（`auto`/尾置返回）；`模板与泛型编程思想.md`。

C++11 中普通函数不能推导返回类型（须尾置 `decltype`）。C++14 允许函数用 `auto` 作为返回类型，由 `return` 语句推导：

```cpp
// C++11
auto add(int a, int b) -> decltype(a + b) { return a + b; }

// C++14
auto add(int a, int b) { return a + b; }
```

- 多个 `return` 必须推导出一致类型。
- 推导规则与 `auto` 一致（剥引用/`const`）。
- 配合 `decltype(auto)`（C++14）可保留引用/`const` 性：

```cpp
decltype(auto) f() { return g(); }   // 保留 g 的返回类型（含引用）
```

**价值**：显著简化泛型函数签名，尤其在返回表达式结果时。

## 3. 变量模板（variable templates）

**所属 C++11 模块**：`模板与泛型编程思想.md`。

C++11 允许模板化的类型与函数。C++14 允许**模板化的变量**：

```cpp
template <typename T>
constexpr T pi = T(3.1415926535897932385);

double p = pi<double>;    // 3.14159...
float  q = pi<float>;     // 3.14159f
```

- 变量模板在实例化时按类型生成独立常量。
- 常用于数学常量、编译期参数化的默认值。

**价值**：避免为每种类型重复定义常量，尤其在数值/类型参数化场景。

## 4. `constexpr` 放宽

**所属 C++11 模块**：`C++核心语法详解.md`（`constexpr`）。

C++11 的 `constexpr` 函数体仅允许单一 `return`。C++14 放开为**普通函数体**，允许局部变量、`if`、循环、`switch` 等：

```cpp
// C++11：仅单 return
constexpr int fact11(int n) { return n <= 1 ? 1 : n * fact11(n - 1); }

// C++14：可写循环
constexpr int fact14(int n) {
    int r = 1;
    for (int i = 2; i <= n; ++i) r *= i;
    return r;
}
static_assert(fact14(5) == 120, "");
```

**价值**：把“编译期计算”从递归模板元编程回归到自然的过程式写法，极大提升 `constexpr` 的表达力与可读性。

## 5. Lambda 初始化捕获（init-capture）

**所属 C++11 模块**：`函数式编程思想.md`（捕获列表）。

C++11 只能按值/按引用捕获已存在变量。C++14 允许在捕获列表内**初始化新变量**，包括**移动捕获**：

```cpp
// 移动捕获
std::unique_ptr<Widget> wp(new Widget);
auto f = [w = std::move(wp)] { return w->use(); };   // 捕获所有权

// 任意表达式初始化
auto g = [x = 1 + 2] { return x; };   // x == 3
```

**价值**：解决“捕获移动语义对象”（如 `unique_ptr`）的难题，是生产代码常用技巧。

---

## 6. 数字分隔符与二进制字面量

**所属 C++11 模块**：`C++核心语法详解.md`（字面量）。

- **二进制字面量**：`0b1010`。
- **数字分隔符**：单引号 `'` 分隔大数字，仅可读性，编译期移除：

```cpp
int bin = 0b1010'1100;         // 172
long long big = 1'000'000'000; // 可读性提升
```

**价值**：改善位运算与大数据字面量的可读性，消除数位笔误。

---

## 7. `[[deprecated]]` 属性

**所属 C++11 模块**：`类和对象.md`（声明与注解）。

标记实体（函数/变量/类型）为**已弃用**，使用处编译器告警：

```cpp
[[deprecated("use new_api() instead")]]
void old_api();

old_api();   // 编译告警提示迁移
```

**价值**：库演进时温和提示使用者迁移，优于硬性删除。

## 8. 标准库增强

**所属 C++11 模块**：`C++常用标准库详解.md`、`STL六大组件全详解.md`。

| 新增/增强 | 说明 |
|---|---|
| `std::make_unique<T>(args...)` | 唯一指针工厂（C++11 需手写） |
| `std::integer_sequence<T,...>` | 编译期整数序列（元编程） |
| `std::index_sequence` | 常用别名 |
| `std::exchange(obj, new)` | 赋值并返回旧值 |
| `std::quoted(s)` | 加引号/转义输出的流操作符 |
| 类型萃取便捷别名 | `std::remove_reference_t<T>` 等 `_t` 后缀 |
| `std::get<T>(tuple)` 支持多 index | 泛型化 |

```cpp
#include <memory>
auto p = std::make_unique<Widget>(1, 2);   // C++14

#include <type_traits>
using T = std::remove_reference_t<int&>;    // int（_t 别名，C++14）
```

**价值**：`make_unique` 与 `_t` 别名大幅简化日常代码，成为现代 C++ 的事实标准写法。
