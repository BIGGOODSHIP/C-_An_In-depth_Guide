## 1. 程序结构、编译单元与 `main`

### 1.1 最小的合法程序

```cpp
int main() { return 0; }
```

`main` 是 C++ 程序的唯一入口（宿主环境程序的约定入口）。其签名合法形式：

```cpp
int main()                         // 最简形式
int main(int argc, char* argv[])   // 带命令行参数
int main(int argc, char** argv)    // 与上等价，argv 为指向首元素的指针
```

- 返回 `0` 或 `EXIT_SUCCESS` 表示正常结束；返回非零表示向宿主报告异常终止。
- `argc`（argument count）为命令行参数个数（含程序名本身），`argv`（argument vector）为参数字符串指针数组。
- `main` 不可被重载、不可被递归调用、不可取其地址（语言层面不允许）。

### 1.2 编译单元（Translation Unit）

一个 `.cpp` 源文件经过预处理后称为一个**编译单元**。每个编译单元独立编译为对象文件（`.o`/`.obj`），随后由链接器合并为可执行文件。这决定了：

- **声明与定义分离**：跨文件使用时必须有声明（头文件），否则编译期报“未声明”。
- **`static`/`extern`/`inline` 的外部链接性规则**决定符号是否跨编译单元可见。
- **头文件重复包含**必须由包含防护（include guard）或 `#pragma once` 解决。

## 2. 基本数据类型与字面量

### 2.1 内置标量类型

| 类型 | 典型宽度（依赖平台） | 用途 | 备注 |
|---|---|---|---|
| `bool` | 1 字节 | 布尔逻辑 | `true`/`false` |
| `char` | 1 字节 | 单字节字符 | 有无符号由实现定义，多为有符号 |
| `signed char` / `unsigned char` | 1 字节 | 显式有符号/无符号字节 | 用于字节运算、`memcpy` 等 |
| `short` / `unsigned short` | 通常 2 字节 | 小整数 | |
| `int` / `unsigned int` | 通常 4 字节 | 通用整数 | 标准仅保证至少 16 位 |
| `long` / `unsigned long` | Windows 4 字节，LP64 平台 8 字节 | 平台相关整数 | |
| `long long` / `unsigned long long` | 至少 8 字节（C++11 正式纳入） | 大整数 | |
| `float` | 4 字节（单精度 IEEE 754） | 浮点 | |
| `double` | 8 字节（双精度） | 浮点主类型 | |
| `long double` | 平台相关（x86 常为 10/16 字节） | 高精度 | |

> **标准保证的最小宽度**：`char`≥8 位、`short`≥16 位、`int`≥16 位、`long`≥32 位、`long long`≥64 位。真实项目一律以 `<cstdint>` 的定宽类型为准（见下文）。

### 2.2 定宽整数类型 `<cstdint>`

```cpp
#include <cstdint>
int8_t  i8;    // 恰好 8 位有符号（若平台不存在则无此类型）
uint64_t u64;  // 恰好 64 位无符号
intptr_t p;    // 足以容纳指针的整数
size_t   n;    // 足以容纳任意对象大小的无符号整数（内存大小/下标）
```

`size_t` 语义上是**无符号**，与 `int` 混用时易引发符号转换告警——这是 C++ 最经典的类型陷阱之一。

### 2.3 字面量

| 字面量 | 示例 | 类型/说明 |
|---|---|---|
| 十进制整数 | `42` | `int`，超出则提升为 `long`/`long long` |
| 八进制 | `052` | 以 `0` 开头，值为 42 |
| 十六进制 | `0x2A` | `int` |
| 二进制 | `0b101010`（C++14 才引入，C++11 不可用） | — |
| 浮点 | `3.14` / `3.14f` / `3.14e2` | `double` / `float` / `double` |
| 字符 | `'A'` / `'\n'` / `'\x41'` | `char` |
| 宽字符 | `L'A'` | `wchar_t` |
| 字符串 | `"hello"` | `const char[N]`（数组，含结尾 `\0`） |
| 原始字符串 | `R"(path\no\escape)"`（C++11） | `const char[N]`，不处理转义 |
| 布尔 | `true` / `false` | `bool` |
| 指针空值 | `nullptr`（C++11） | `std::nullptr_t` |
| 用户自定义字面量 | `123_km`（C++11） | 见标准库章节 |

字符转义序列：`\n` 换行、`\t` 制表、`\\` 反斜杠、`\'` 单引号、`\"` 双引号、`\0` 空字符、`\xhh` 十六进制字节、`\ooo` 八进制字节。

### 2.4 类型转换

- **隐式转换（标准转换）**：算术提升（`char`→`int`）、`int`→`long`、`int`→`double` 等；由窄变宽安全，由宽变窄（如 `double→int`）会**截断**并可能告警。
- **`static_cast<目标>(表达式)`**（C++11 起推荐）：编译期可验证的显式转换，如 `static_cast<int>(3.7)`。
- **`const_cast<T>`**：去除/添加 `const`，仅在对象本非 `const` 时可安全使用。
- **`reinterpret_cast<T>`**：按位重解释指针/整数，危险，仅底层场景使用。
- **旧式转换 `(int)x`**：语义等价于上述组合，审查代码时应替换为显式新式转换。
- **`dynamic_cast<T>`**：多态类型的安全下行/交叉转换，运行时检查，见「类和对象」。

## 3. 变量、作用域与存储期

### 3.1 声明、定义与初始化

```cpp
extern int g;   // 声明：承诺存在，不分配
int g = 1;      // 定义：分配并初始化
int a;          // 定义（默认初始化）
int b{};        // 值初始化：标量置 0（C++11）
int c{5};       // 列表初始化（C++11）
auto d = 5;     // 类型推导为 int（C++11）
```

### 3.2 作用域（Scope）

| 作用域 | 可见范围 | 生命周期 |
|---|---|---|
| 块作用域（`{}`） | 声明点至块结束 | 局部变量：进入块分配（栈），退出块销毁 |
| 函数原型作用域 | 仅在形参列表内 | — |
| 命名空间作用域 | 命名空间内 | 全局/命名空间对象：静态存储期 |
| 类作用域 | 类内 | — |
| 枚举作用域（C++11 强类型枚举） | 枚举内 | — |

### 3.3 存储期（Storage Duration）

| 存储期 | 分配位置 | 生命周期 | 关键字 |
|---|---|---|---|
| 自动存储期 | 栈 | 块执行期间 | 默认；`auto`（仅局部默认） |
| 静态存储期 | 静态区 | 程序启动→结束 | `static`、命名空间级 |
| 线程存储期 | 线程局部 | 线程启动→结束 | `thread_local`（C++11） |
| 动态存储期 | 堆 | `new` 至 `delete` | `new`/`delete` |

**栈与堆**：

- 栈：容量小（默认数 MB），分配/释放极快，随作用域自动管理，不适合大对象与跨函数返回。
- 堆：容量大，分配慢，必须手工 `new`/`delete`，存在泄漏与悬挂风险。现代实践用 RAII 与智能指针封装（见标准库章节）。

### 3.4 常量限定符

```cpp
const int k = 3;        // 运行期或编译期常量；对象不可修改
constexpr int k2 = 4;   // C++11：编译期常量，必须在编译期求值
```

- `const` 修饰的是“该对象不可通过此路径修改”，不必然等于编译期常量。
- `constexpr` 强约束：函数若标注 `constexpr`，必须满足可编译期求值（单一 return 语句体在 C++11 中）。

## 4. 运算符与表达式

### 4.1 算术、关系、逻辑、位运算

| 类别 | 运算符 |
|---|---|
| 算术 | `+ - * / %`（`%` 仅整数） |
| 自增自减 | `++i i++ --i i--`（前缀/后缀的求值时机与返回值不同） |
| 关系 | `< > <= >= == !=` |
| 逻辑 | `&& || !`（短路求值：`a && b` 中若 `a` 假则不求 `b`） |
| 位 | `& | ^ ~ << >>`（仅整数类型） |
| 赋值 | `= += -= *= /= %= &= |= ^= <<= >>=` |
| 条件 | `cond ? a : b`（三目，返回值） |
| 逗号 | `a, b`（依次求值，整体取右侧） |
| 成员/指针 | `. -> ::` |
| 求大小 | `sizeof`（对象/类型）、`sizeof...(pack)`（C++11 包长度） |
| 类型转换 | `static_cast` 等 |
| 内存 | `new delete new[] delete[]` |
| 其他 | `* &`（解引用/取址）、`typeid` |

### 4.2 运算符优先级（从高到低，核心片段）

`::` → `()` `[]` `->` `.` → 后缀`++/--` → 前缀`++/--` `! ~ + - & *` → 强制转换 → `* / %` → `+ -` → `<< >>` → `< <= > >=` → `== !=` → `&` → `^` → `|` → `&&` → `||` → `?:` → 赋值 → 逗号。

> 工程铁律：**凡优先级可能引起歧义处，一律用括号显式分组**，不依赖记忆优先级。

### 4.3 求值顺序与副作用（C++11 语义）

C++11 中，`&&`、`||`、`?:`、逗号运算符保证顺序求值；其余二元运算符（如 `a + b`）**不保证** `a` 与 `b` 的求值先后。在同一表达式内对同一对象**写多于一次**或**先写后读**且存在未指定顺序时，属于**未定义行为（UB）**：

```cpp
int i = 0;
i = i++ + 1;   // 未定义行为：对 i 的两次写无顺序保证
```

## 5. 流程控制（分支与循环）

### 5.1 分支

```cpp
if (cond) { } else if (c2) { } else { }

switch (expr) {           // expr 必须为整数或枚举
  case 1:  ...; break;    // 忘写 break 会“贯穿”到下一 case
  case 2:  ...; [[fallthrough]];  // C++17 才有该属性，C++11 直接续写
  default: ...;
}
```

`switch` 中不可在未初始化变量的情况下列出 `case`（跨 case 初始化非法）。

### 5.2 循环

```cpp
for (init; cond; incr) { }
while (cond) { }
do { } while (cond);
```

- `break`：退出最内层循环/`switch`。
- `continue`：跳过本次循环体剩余部分，进入下一次迭代。
- 无限循环：`for(;;)` 或 `while(true)`。

### 5.3 范围 for（C++11）

```cpp
int arr[] = {1,2,3};
for (int v : arr) { ... }          // 按值
for (int& v : arr) { v *= 2; }     // 按引用可修改
for (const auto& v : arr) { ... }  // 只读且避免拷贝
```

范围 for 要求容器支持 `begin()`/`end()`（或数组），并遍历 `[begin, end)`。

## 6. 函数：声明、定义、重载、默认实参、内联

### 6.1 声明与定义

```cpp
// 声明（仅签名）
int add(int a, int b);

// 定义（含函数体）
int add(int a, int b) { return a + b; }

// 调用
int r = add(3, 4);
```

函数声明必须在使用前可见。若只在定义后才调用，须保证顺序。

### 6.2 参数传递语义

- **按值**：拷贝实参，函数内修改不影响调用者。
- **按引用**（`int&`）：共享同一对象，可修改调用者变量；避免大对象拷贝。
- **按常量引用**（`const int&`）：只读共享，推荐作为只读参数默认方式。
- **按指针**（`int*`）：传地址，可修改指向对象；可为 `nullptr` 表示“无”。
- **数组参数退化**：`void f(int a[])` 实际是 `void f(int* a)`，不拷贝数组。

### 6.3 返回值

- 返回标量/对象：按值返回（C++11 有返回值优化 RVO/移动优化）。
- 返回大对象：可返回局部对象（移动/拷贝省略），**不要返回局部变量的指针或引用**（悬挂）。
- 返回引用：可返回“实参的引用”或“成员引用”，用于链式调用。

### 6.4 默认实参

```cpp
void log(int level, const std::string& msg, bool flush = true);
```

- 默认实参只能出现在**声明**或**定义**之一处（通常放声明）。
- 有默认实参的参数必须位于参数列表**末尾**。

### 6.5 函数重载（Overload）

同一作用域内，多个同名函数只要**形参列表不同**（类型、个数、`const` 限定）即构成重载，编译器按实参匹配最佳候选：

```cpp
int  max(int a, int b);
double max(double a, double b);
std::string max(const std::string&, const std::string&);
```

重载解析规则（粗略优先级）：精确匹配 → 平凡转换 → 提升 → 标准转换 → 用户定义转换。`nullptr` 只能匹配指针/`nullptr_t`，从而解决历史遗留的 `NULL` 二义性问题（C++11 关键改进）。

### 6.6 内联函数

```cpp
inline int sq(int x) { return x * x; }
```

- 提示编译器在调用处展开以消除调用开销，但**语义上仍是函数**（有作用域、参数检查）。
- 头文件中定义的函数若想跨编译单元使用且不违反 ODR，用 `inline`。
- 是否真正内联由编译器权衡决定，`inline` 只是建议。

### 6.7 函数指针

```cpp
int add(int,int);
int (*pf)(int,int) = &add;   // 指向函数
int r = pf(3,4);
using Fn = int(*)(int,int);  // C++11 类型别名
```

函数指针可用于回调、表驱动等；C++11 推荐用 `std::function` 封装更灵活的可调用对象（见函数式编程章节）。

## 7. 数组与字符串

### 7.1 C 风格数组

```cpp
int a[5];                 // 未初始化（自动存储期时为不确定值）
int b[5] = {1,2,3};       // 余下补 0
int c[]  = {1,2,3};       // 长度由初始化推导为 3
int d[3] = {};            // 全 0
const int n = 5; int e[n]; // C++ 中 n 为编译期常量即可（非 VLA）
```

- 数组名在多数表达式中退化为指向首元素的指针。
- `sizeof(a)/sizeof(a[0])` 在数组**本身**作用域内可算长度；一旦退化传参则失效。
- 越界访问是未定义行为（UB），现代 C++ 优先用 `std::array` / `std::vector`。

### 7.2 多维数组

```cpp
int m[2][3] = {{1,2,3},{4,5,6}};
// 按行主序存储；m[1][2] == 6
```

### 7.3 C 字符串（字符数组）

```cpp
const char* s = "hello";   // 指向字符串字面量（只读，长度 5，占用 6 含 '\0'）
char buf[6];               // 拷贝需手动确保空间足够并结尾 '\0'
```

C 字符串函数（`strlen`/`strcpy`/`strcmp`/`strcat` 等）无边界检查，极易缓冲区溢出。C++ 应优先使用 `std::string`（见常用标准库章节），仅在互操作 C 接口时使用 `c_str()`。

## 8. 指针：原生指针、`nullptr`、多级指针、指针运算

### 8.1 指针基础

```cpp
int v = 42;
int* p = &v;      // p 保存 v 的地址
*p = 100;         // 解引用，写 v
int** pp = &p;    // 二级指针：指向指针的指针
```

### 8.2 `nullptr`（C++11）

```cpp
int* p = nullptr;   // 类型 std::nullptr_t，可隐式转为任意指针/成员指针
int* q = 0;         // 0 亦可，但重载决议上 nullptr 更精确
if (p == nullptr) { }
```

- `nullptr` 解决了 `NULL`（实为整数 0）在重载 `void f(int)` 与 `void f(char*)` 时的二义性。
- **解引用空指针是未定义行为**，绝大多数平台表现为崩溃。

### 8.3 指针运算与数组关系

```cpp
int a[5];
int* p = a;      // 指向 a[0]
p + 2;           // 指向 a[2]：按 sizeof(int) 缩放
*(p + i) == a[i]; // 恒等
p - q;           // 同数组内指针差 = 元素个数差
```

- 指针越出数组边界（除末尾后一位置）即 UB。
- 指针运算只允许在**同一数组对象**内进行。

### 8.4 `const` 与指针的三种组合

```cpp
const int* p1;      // 指向 const int：可改 p1，不可改 *p1
int* const p2;      // const 指针：不可改 p2，可改 *p2
const int* const p3;// 二者皆不可改
```

### 8.5 动态内存与 `new`/`delete`

```cpp
int* p  = new int(5);        // 单对象
int* arr = new int[10];      // 数组
delete p;   delete[] arr;    // 必须配对使用，数组必须 delete[]
```

- `new[]` 与 `delete[]` 混用是 UB。
- 分配失败默认抛出 `std::bad_alloc`。
- 现代 C++ 以 RAII（智能指针/容器）取代裸 `new`/`delete` 管理生命周期。

## 9. 引用：左值引用、常量引用、右值引用与移动语义

### 9.1 左值与右值（C++11 值类别）

- **左值（lvalue）**：有名字、有地址、可持久存在的表达式（变量、解引用、成员）。
- **右值（rvalue）**：临时、即将销毁的表达式（字面量、临时对象、`std::move` 结果）。
- C++11 引入的完整体系分为 `glvalue`（左值/泛左值）与 `rvalue`（`xvalue`/`prvalue`）。工程上掌握“有身份有持久性=左值，临时=右值”即可。

### 9.2 左值引用

```cpp
int v = 1;
int& r = v;      // 引用是 v 的别名，无独立存储（实现上是指针）
r = 2;           // 等价于 v = 2
const int& cr = v;  // 只读引用
```

引用**必须初始化**、不可重新绑定到其他对象、不占用显式存储。适用于参数/返回，避免拷贝。

### 9.3 右值引用（C++11）

```cpp
int&& rr = 5;           // 可绑定右值
std::string&& s = std::string("temp"); // 延长临时生命周期
```

右值引用可以修改所绑定的临时对象（其即将销毁），这正是**移动语义**与**完美转发**的基础。

### 9.4 移动语义与 `std::move`

```cpp
std::vector<int> big = build();
std::vector<int> target = std::move(big);  // 将 big 的资源“搬”给 target
// 移动后 big 处于“合法但未指定”状态，一般只剩空壳，可重新赋值
```

- 移动构造/移动赋值：把源对象堆资源的所有权转移给目标，避免深拷贝。
- `std::move` 本身只做**无条件右值转换**，不搬移任何数据，真正搬移发生在移动构造函数。
- 移动后源对象必须保持**可析构、可赋值、可再使用**的不变量。
- 右值引用参与的**完美转发**用 `std::forward`（见模板章节）。

## 10. 结构体、联合体与枚举

### 10.1 结构体 `struct`

```cpp
struct Point { double x; double y; };      // 默认公有成员
Point p1;                  // 默认初始化：内置成员未初始化
Point p2{1.0, 2.0};        // C++11 聚合初始化
Point p3 = {1.0, 2.0};     // 等价
```

聚合类型（C++11）：无用户提供构造函数、无非静态私有成员、无基类、无虚函数的类可用花括号聚合初始化。

### 10.2 联合体 `union`

```cpp
union U { int i; float f; };
U u; u.i = 3;      // 同一块内存，不同成员共用；同一时刻只有一个成员活跃
```

- 所有成员共享同一存储，大小取最大成员（含对齐）。
- C++11 起非静态成员可为带构造函数/析构函数的类类型，但需要时须手工构造/析构（易错，慎重）。

### 10.3 枚举

```cpp
enum Color { Red, Green, Blue };   // C 风格枚举：可隐式转 int，作用域泄漏
enum class Status : int { Ok = 0, Fail = 1 };  // C++11 强类型枚举
Status s = Status::Ok;             // 必须限定访问
int v = static_cast<int>(s);       // 需显式转换
```

- 强类型枚举**不会**隐式转为整数，避免命名冲突与隐式转换隐患。
- 可指定底层类型（默认为 `int`），影响大小与位布局。

## 11. C++11 语法特性集锦

> 以下均为 C++11 引入的**语法层**新能力，已在上文分布提及，此处集中归纳以便查阅。

### 11.1 `auto` 类型推导

```cpp
auto v = 3.14;              // double
auto it = container.begin();// 迭代器类型
auto& r = v;                // 推导含引用/const 时需显式声明
const auto c = 5;
```

`auto` 在**声明处推导**，不推导数组为值、不推导模板实参（需 `decltype` 等配合）。主要价值：避免冗长类型名、消除类型书写错误、配合范围 for 简洁遍历。

### 11.2 `decltype`

```cpp
int a; decltype(a) b;        // int（保留引用/const 性）
decltype((a)) r = a;         // int&（加括号变为表达式求引用）
template<typename T> auto f(T t) -> decltype(t.x); // 尾置返回类型
```

`decltype(实体)` 精确推导实体类型（含 `const`、引用）；`decltype(表达式)` 推导表达式求值结果的类型（左值表达式得引用）。

### 11.3 尾置返回类型

```cpp
template<typename T, typename U>
auto add(T a, U b) -> decltype(a + b) { return a + b; }
```

参数未定义完时无法在头部写返回类型，尾置返回解决此问题，常与 `auto` 联用。

### 11.4 统一初始化与 `initializer_list`

```cpp
std::vector<int> v{1,2,3};       // 列表初始化
Point p{1.0, 2.0};
int x{};                         // 值初始化置 0
// 注意：std::vector<int> v(5) 是 5 个 0；v{5} 是 1 个元素值为 5 —— 经典陷阱
```

花括号初始化禁止**窄化转换**（如 `double` → `int` 编译报错），比括号初始化更安全，是推荐默认。

### 11.5 范围 `for`

见 §5.3。

### 11.6 `nullptr`

见 §8.2。

### 11.7 移动语义与右值引用

见 §9。

### 11.8 `constexpr`

```cpp
constexpr int square(int x) { return x * x; }  // C++11：体须为单一 return
constexpr int k = square(5);   // 编译期求值
```

### 11.9 原始字符串字面量

```cpp
const char* path = R"(C:\Users\name)";  // 不转义，适合正则、路径、JSON
```

### 11.10 `using` 类型别名

```cpp

```


## 12. 头文件、命名空间与预处理

### 12.1 头文件组织

- 头文件放**声明**与 `inline` 定义；`.cpp` 放定义。
- 包含防护：

```cpp
#ifndef LIB_UTIL_H
#define LIB_UTIL_H
// ...
#endif
```

或 `#pragma once`（非标准但被主流编译器普遍支持）。

- **ODR（单一定义规则）**：实体（函数、类、变量）在整个程序内最多一个定义；`inline` 函数与类定义可出现在多个编译单元且须一致。

### 12.2 命名空间

```cpp
namespace util { int f(); }
using util::f;             // 引入单个名字
using namespace util;      // 引入全部（在头文件中禁止，易命名冲突）
namespace util { int f() { return 1; } }  // 重开命名空间继续定义
```

- 匿名命名空间 `namespace { }` 内的实体具有**内部链接**，等价于文件级 `static`。
- C++11 支持**内联命名空间** `inline namespace`（对版本控制/ABI 平滑演进有意义）。

### 12.3 常用预处理指令

```cpp
#include <...>      // 系统头文件路径
#include "..."      // 当前目录优先
#define / #undef    // 宏定义/取消
#ifdef / #ifndef / #if / #else / #endif   // 条件编译
#pragma once        // 头文件只包含一次
#error "msg"        // 编译期报错
# 与 ##             // 字符串化与记号粘合（宏元编程，谨慎使用）
```

> 宏无类型、无作用域、易产生二义性。工程准则：能用 `const`/`constexpr`/`inline`/`enum`/模板替代宏的，一律不用宏。

## 13. 异常处理基础

```cpp
try {
    risky();            // 可能抛出
} catch (const std::exception& e) {
    std::cerr << e.what() << '\n';
} catch (...) {         // 捕获一切（用于兜底清理）
}
```

- `throw` 抛出异常对象（推荐派生自 `std::exception` 的值对象）。
- 异常沿调用栈逐层展开，逐层析构自动存储期对象（栈展开，stack unwinding）。
- `noexcept`（C++11）：声明函数不抛异常；违反则调用 `std::terminate`。
- **异常安全等级**：基本保证（不泄漏、对象一致）、强保证（要么成功要么状态不变）、无抛出保证。
- RAII 是异常安全的关键：析构释放资源，天然回滚。
- 不建议在 `noexcept` 析构函数中抛出（会终止程序）；资源管理避免裸指针以防中途抛出泄漏。

## 14. 综合应用与常见陷阱

### 14.1 一个完整的可编译示例

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>

int main() {
    std::vector<std::string> words{"lambda", "core", "syntax"};
    std::sort(words.begin(), words.end(),
              [](const std::string& a, const std::string& b) {
                  return a.size() < b.size();
              });
    for (const auto& w : words)
        std::cout << w << '\n';
    return 0;
}
```

### 14.2 高频陷阱清单

| 陷阱 | 说明 | 对策 |
|---|---|---|
| 悬垂指针/引用 | 返回局部对象地址 | 返回值/智能指针 |
| 数组退化 | 传参后 `sizeof` 失效 | 用容器或显式传长度 |
| 符号转换 | `int` 与 `size_t` 混用 | 用 `size_t`/显式转换 |
| 窄化初始化 | 花括号内 `double→int` | 依赖 C++11 报错检查 |
| `vector(5)` vs `{5}` | 元素个数 vs 单个元素 | 明确两种初始化语义 |
| `new`/`delete` 不配对 | 泄漏/UB | RAII/智能指针 |
| 越界访问 | 数组/`vector::operator[]` 不检查 | `at()` 或迭代器 |
| 未定义行为 | 整数溢出、悬垂、UB 依赖 | 遵循规范 |
| 宏污染 | 无作用域宏 | 用 `constexpr`/`inline` |
| 浅拷贝 | 裸指针成员拷贝 | 深拷贝或移动语义 |
