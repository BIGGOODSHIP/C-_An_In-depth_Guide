# 函数式编程思想

> 函数式编程（Functional Programming, FP）是一种把**计算抽象为函数的求值**、强调**不可变性**与**高阶函数**的编程范式。C++11 通过 Lambda 表达式、`std::function`、`std::bind` 与算法库把函数式能力系统地引入主语言。本文件严格限定在 C++11 及之前标准。

## 1. 函数式编程的核心思想

函数式范式的三条支柱，在 C++ 中的映射：

| FP 原则 | 含义 | C++ 落点 |
|---|---|---|
| 纯函数（pure function） | 输出仅由输入决定，无副作用 | `const` 函数、无捕获/只读捕获 Lambda |
| 不可变性（immutability） | 数据一旦创建不再修改，用新值替换 | `const`、返回新容器、`std::copy` 等 |
| 高阶函数（higher-order） | 函数可作为参数/返回值/被组合 | Lambda、`std::function`、STL 算法 |

C++ 并非纯函数式语言（保留可变状态与 OO），但可**以函数式风格组织局部逻辑**：用高阶算法表达“对集合做什么”，而非手写循环“怎么遍历”。

## 2. 可调用对象（Callable）体系

C++ 中“可调用对象”涵盖一切可用 `f(args)` 调用的实体：

1. **普通函数**（含函数指针）。
2. **Lambda 表达式**（C++11）。
3. **函数对象 / 仿函数**：重载 `operator()` 的类对象。
4. **`std::bind` 产生的绑定对象**（C++11）。
5. **成员函数指针**（配合 `std::mem_fn` / `std::bind`）。

统一的抽象由 `std::function` 承载（类型擦除），也可由模板 `F&&` 通用引用承载（零开销，保留具体类型）。

### 2.1 函数对象（function object）

```cpp
struct Add {
    int operator()(int a, int b) const { return a + b; }
};
Add add; add(1, 2);   // 可带状态（成员变量），是“带数据的函数”
```

仿函数相对函数指针的优势：**可携带状态**、可内联（无间接调用）、可被模板实例化。

## 3. Lambda 表达式（C++11）

Lambda 是 C++11 引入的**就地定义的匿名函数对象**，编译器会为每个 Lambda 生成一个唯一的闭包类型（closure type）。

### 3.1 完整语法

```cpp
[capture] (params) mutable -> ret_type { body }
```

- `[capture]`：捕获列表。
- `(params)`：形参列表（可省略）。
- `mutable`：允许修改按值捕获的副本（默认 `operator()` 为 `const`）。
- `-> ret_type`：尾置返回类型，可省略由编译器推导。
- `{ body }`：函数体。

### 3.2 最简示例

```cpp
auto add = [](int a, int b) { return a + b; };   // 无捕获
int r = add(1, 2);
```

### 3.3 按值/按引用捕获

```cpp
int base = 10;
auto f1 = [base](int x) { return base + x; };        // 按值捕获副本
auto f2 = [&base](int x) { base += x; };             // 按引用捕获，可修改外部
auto f3 = [=](int x) { return x; };                  // 全部按值（默认捕获）
auto f4 = [&](int x) { return x; };                  // 全部按引用
auto f5 = [=, &base]() {};                           // 混合：除 base 按引用外按值
auto f6 = [&, base]() {};                            // 混合：除 base 按值外按引用
```

- 按值捕获的是**创建时**的副本（默认拷贝）。
- 按引用捕获的是**外部对象的引用**，生命周期风险（悬垂引用）由调用方负责。

### 3.4 初始化捕获（C++11 中初始化列表式捕获见 C++14，本文件以值/引用捕获为准）

```cpp
int x = 42;
auto f = [x]() { return x; };   // 值捕获（C++11 支持）
```

> 移动捕获、`[x = expr]` 泛型初始化捕获属于 C++14，见 `现代C++/C++14新增特性.md`。

### 3.5 Lambda 与函数指针的转换

**无捕获**的 Lambda 可隐式转换为同签名函数指针；**有捕获**的 Lambda 因携带状态，无法转函数指针，须用 `std::function` 或模板承载。

## 4. 捕获列表与捕获时机（C++11）

### 4.1 捕获的实质

- 按值捕获：Lambda 对象构造时拷贝一份副本（闭包成员）。
- 按引用捕获：闭包保存引用（实现上为指针），指向外部对象。

### 4.2 悬垂引用陷阱

```cpp
std::function<int()> bad() {
    int x = 5;
    return [&x]() { return x; };   // x 出函数即销毁，返回引用悬垂 —— UB
}
```

按引用捕获逃逸出被捕获对象作用域是 C++ 函数式编程**最高频缺陷**。对策：

- 需要逃逸的 Lambda 一律**按值捕获**（副本安全）。
- 按引用捕获仅用于生命周期明确包裹（如同作用域内的回调）。

### 4.3 `mutable` 与按值捕获修改

```cpp
int n = 0;
auto counter = [n]() mutable { return ++n; };   // 修改的是闭包内副本
counter();   // 1；外部 n 仍为 0
```

不加 `mutable` 时，按值捕获副本在 `operator()` 内视为 `const`，不可修改。

## 5. `std::function`：类型擦除的可调用对象（C++11）

头文件 `<functional>`。`std::function` 用类型擦除（type erasure）把任意可调用对象统一到同一签名类型：

```cpp
#include <functional>
std::function<int(int, int)> fn;

fn = [](int a, int b) { return a + b; };          // Lambda
fn = &multiply;                                    // 函数指针
fn = MultiplyFunctor{};                            // 仿函数
fn = std::bind(add, std::placeholders::_1, 10);    // 绑定对象
```

### 5.1 核心接口

- 默认构造：空状态（empty），`operator bool` 为 `false`。
- 赋值/构造：接受任意兼容的可调用对象。
- `operator()`：调用；空对象调用抛 `std::bad_function_call`。
- `swap`、比较（`==`/`!=`，仅判断是否同一目标，C++11 有限支持）。

### 5.2 典型场景

- **回调注册**（事件、异步完成）。
- **策略注入**（策略模式：把行为作为数据传递）。
- **泛型算法适配**（把“条件”抽象为可调用对象）。
- **延迟执行 / 函数表**。

### 5.3 成本认知

`std::function` 通过虚调用实现类型擦除，且有堆分配的可能（小对象优化不完全）。热路径、性能敏感场景应改用**模板参数**（通用引用 + 内联）：

```cpp
template <typename F>
void run(F&& fn) { fn(); }    // 保留具体类型，可内联，零间接调用
```

## 6. `std::bind` 与部分应用（C++11）

### 6.1 占位符与绑定

```cpp
using namespace std::placeholders;

int add(int a, int b) { return a + b; }

auto add5 = std::bind(add, 5, _1);     // 固定第一参数为 5，第二参数由调用传入
add5(10);                               // == 15

auto rev  = std::bind(add, _2, _1);    // 参数交换
rev(10, 20);                            // == 30（传入顺序 10,20，绑定为 (20,10)）
```

### 6.2 绑定成员函数与成员

```cpp
struct S { void show(int x) const {} };
S s;
auto f = std::bind(&S::show, &s, _1);   // 绑定成员函数到对象
f(1);
```

### 6.3 与 Lambda 的关系

- `std::bind` 是函数式“部分应用/柯里化”的直接工具，但写法晦涩、错误信息差。
- 现代 C++ 实践中，**Lambda 通常优于 `std::bind`**（更清晰、捕获更可控、性能相近）；`std::bind` 主要用于 `std::function` 初始化与旧式回调适配。

## 7. 高阶函数与算法组合

### 7.1 STL 算法即高阶函数

```cpp
std::vector<int> v{3,1,4,1,5};
std::sort(v.begin(), v.end());                          // 默认 <
std::sort(v.begin(), v.end(), std::greater<int>());     // 传入比较仿函数
std::transform(v.begin(), v.end(), v.begin(),
               [](int x) { return x * x; });            // 映射 map
```

- `std::find_if`、`std::count_if`、`std::remove_if`：以“谓词（predicate）”为参数。
- `std::accumulate`：折叠（fold/reduce）。
- `std::for_each`：对每个元素应用副作用操作。

### 7.2 谓词的三分类（C++11）

| 谓词 | 返回值 | 示例 |
|---|---|---|
| 一元谓词 | `bool`（对单个元素） | `[](int x){return x>0;}` |
| 二元谓词 | `bool`（对两元素，用于排序/比较） | `std::less<int>` |
| 转换函数 | 任意类型（map） | `[](int x){return x*2;}` |

### 7.3 组合思路

函数式风格把“业务规则”写成小函数/小 Lambda，再通过高阶算法**组合**，替代长循环中的临时状态机：

```cpp
std::vector<int> data{...};
auto is_even = [](int x) { return x % 2 == 0; };
auto square = [](int x) { return x * x; };
int sum = std::accumulate(
    data.begin(), data.end(), 0,
    [&](int acc, int x) { return acc + (is_even(x) ? square(x) : 0); });
```

## 8. 不可变性与纯函数实践

### 8.1 纯函数的好处

- **可测试**：给定输入必然同一输出，无需 mock 外部状态。
- **可组合**：结果可作为输入安全传递，无隐式依赖。
- **并发安全**：无共享可变状态，天然免锁。

### 8.2 在 C++ 中推行不可变性

- 参数用 `const T&`；函数返回新值而非就地修改。
- 成员用 `const`、容器声明 `const` 引用传递。
- 需要修改集合时，用 `std::copy` + 算法生成新容器，保留原数据。

### 8.3 平衡：纯函数式 vs 命令式

C++ 的价值在于**按场景择范式**：

- 数据转换管线：函数式（`map`/`filter`/`fold` 语义清晰）。
- 需要就地高性能：命令式 + 迭代器 + 模板（零抽象）。
- 两者可混排：函数式表达“是什么”，命令式负责“如何高效”。

## 9. 函数式风格在 STL 中的应用

### 9.1 标准库对 FP 的直接支撑（C++11）

- `<functional>`：`std::function`、`std::bind`、`std::ref`/`std::cref`、`std::less` 等算术/关系仿函数。
- `<algorithm>`：大量以谓词/转换函数为参数的高阶算法。
- 容器构造可用仿函数（如 `std::set<int, std::greater<int>>`）。

### 9.2 谓词仿函数速查（C++11）

| 仿函数 | 语义 |
|---|---|
| `std::less<T>` / `std::greater<T>` | `a<b` / `a>b` |
| `std::plus<T>` / `std::minus<T>` | `a+b` / `a-b` |
| `std::logical_and<T>` | `a&&b` |
| `std::equal_to<T>` | `a==b` |

### 9.3 Lambda 驱动算法示例

```cpp
std::map<std::string,int> m{...};
auto it = std::find_if(m.begin(), m.end(),
    [](const auto& kv) { return kv.second > 100; });   // 按值筛选
```

## 10. 性能、生命周期与陷阱

### 10.1 性能对比

| 承载方式 | 调用开销 | 是否可内联 | 状态 |
|---|---|---|---|
| 模板 `F&&` | 最低（直接调用） | ✔ | 保留具体类型 |
| 函数指针 | 间接调用 | 通常不可 | 无状态 |
| Lambda（直接调用） | 最低（可内联） | ✔ | 闭包 |
| `std::function` | 虚调用/类型擦除 | 困难 | 任意可调用对象 |

结论：**性能热路径用模板或裸 Lambda；接口抽象用 `std::function`。**

### 10.2 生命周期陷阱清单

| 陷阱 | 说明 | 对策 |
|---|---|---|
| 引用捕获逃逸 | 闭包存活超过被捕获对象 | 按值捕获/延长对象寿命 |
| `std::function` 空调用 | 抛 `std::bad_function_call` | 调用前判空 |
| 捕获 `this` 悬垂 | Lambda 逃逸后 `this` 已销毁 | 谨慎，确保生命周期 |
| 大对象按值捕获 | 拷贝开销 | 按引用（保证寿命）或移动捕获（C++14） |
| 闭包类型不可复制 | 无捕获可转函数指针；有状态不可 | 用 `std::function`/模板 |

### 10.3 设计建议

- 回调、事件、异步完成回调：`std::function` + 按值捕获安全副本。
- 算法内部条件：模板谓词/Lambda，保持内联与零开销。
- 跨模块 ABI：函数指针或 C 接口。
- 记住：**引用捕获是“借用”，值捕获是“拥有”**——按生命周期需求选择。
